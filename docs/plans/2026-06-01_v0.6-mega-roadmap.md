## TIER 0 — BUG FIXES (Do First)

### Bug 5: Event Loop / Thread Leak
- **Root cause:** `idle_timer_thread` spawns new threads with `asyncio.run()`, creating NEW event loops. Previous WS connections not closed properly, `asyncio.Lock` objects bound to old loop.
- **Fix:** Stop creating new threads per idle cycle — reuse single dedicated thread/loop. Properly close WS on restart. Use `threading.Lock` instead of `asyncio.Lock` for cross-thread resources.
- **Effort:** 4-6 jam
- **Risk:** Medium

### Bug 6: Lampu/Nametag Stuck
- **Root cause chain:**
  1. `trigger_expression_state("default")` should turn OFF ArtiMikir
  2. `_fallback_reset_lamp()` waits 5s, checks `if idle_expression_active: skip`
  3. Idle restarts within ~2s → fallback ALWAYS skips
  4. ArtiDefault1 doesn't explicitly set emblem parameter to 0
- **Fix approaches (pick one or combo):**
  - Ensure ALL expression files have emblem=0 (VTS editor, 30 min)
  - Fix Bug 5 first (root cause)
  - Add explicit emblem reset via `InjectParameterDataRequest` when entering "default"
  - Remove 5s delay in `_fallback_reset_lamp`
- **Effort:** 30 min - 2 jam
- **Risk:** Low

### Bug 7: Supertone Quality (5 min fix!)
- **Root cause:** `total_steps=8` (real-time) vs sample files likely used `12` (offline max quality). Diffusion model with fewer steps = less detailed/expressive.
- **Fix:**
  - `supertonic_total_steps: 8 → 10` (+0.5-1s latency)
  - `supertonic_speed: 1.0 → 0.95` (pitch naik sedikit, lebih "cerah")
  - Combo: `steps=10, speed=0.95` = closest to sample quality
- **Effort:** 5 menit
- **Risk:** Very low

### Bug 2: Lip Sync Delay
- **Root cause:** `tts_is_playing` set True only at audio PLAYBACK start. During TTS synthesis (2-5s), `tts_is_playing` still False → motions can fire.
- **Fix:** Set `tts_is_playing = True` EARLIER — saat API call mulai. Or add "pre-speech" state that stops motions saat "mikir".
- **Effort:** 2 jam
- **Risk:** Low

### Bug 3: Latency Logging (Diagnostic First!)
- **Current:** ZERO timing data for end-to-end response chain
- **Chain:** Mic→ASR (1-3s) → LLM (1-5s) → TTS (2-5s) → Playback → Lip sync = **5-15s total**
- **Fix:** Add `time.perf_counter()` at each step. Log to session log.
- **Effort:** 1 jam
- **Risk:** None (purely diagnostic)

### Bug 4: Supertone Fallback Resilience
- **Root cause:** 20s timeout exceeded under CPU pressure. Happened 2x in 1 session during high-activity.
- **Fix:**
  - Increase timeout 20s → 30s (5 min)
  - Auto-retry Supertone once before fallback (30 min)
  - Log Supertone synthesis time per utterance (30 min)
  - Priority CPU affinity for Supertone subprocess (1 jam)
  - Reduce total_steps 8→6 during high-load (30 min)
- **Effort:** 1-3 jam
- **Risk:** Low

### Bug 8: Subtitle Kepanjangan
- **Current:** ALL phrases rendered at once → tiny text for long responses
- **Fix:** Show ONLY current sentence in yellow. Swap on next.
- **File:** Only `subtitle.html` needs changes (lines 267-342)
- **Changes:**
  - Replace phrase renderer: show only current phrase
  - Replace word renderer: group words into sentences
  - Simplify CSS: remove `.said` class
  - Bump font: 28px → 36px
- **No backend changes needed**
- **Effort:** 1-2 jam
- **Risk:** Very low

## TIER 2 — AMBITIOUS

### Feature 5: Screen Reaction / Vision (FREE)
- **Recommended:** Groq Vision (Llama 4 Scout) — already have key, 30 RPM free
- **Pipeline:** Screenshot every 5s (mss) → Groq Vision → feed as `[SCREEN: ...]` context
- Don't auto-speak — enrich context for when Arti IS triggered
- Rate limit: max 10 vision calls/min
- **Cost:** $0
- **Effort:** 8-12 jam

### Feature 3: Custom Voice via RVC (FREE)
- **Pipeline:** Edge TTS → RVC voice conversion → VB-Cable → VTS
- **Why:** Any custom voice, ~300-500ms (faster than Supertone)
- **Tradeoff:** Loses expression tags (`<laugh>`, `<sigh>`). Keep Supertone as fallback.
- **RVC training:** 10+ min clean audio, ~1-2 hours on GTX 1650
- **Tool:** Applio (modern RVC fork, MIT license)
- **Cost:** $0
- **Effort:** 6-10 jam

### Feature 2: AR Composite (FREE, 30 min!)
- Level 1: VTube Studio (transparent BG) → OBS layer → over webcam
- Already possible with current setup!
- Level 2: iPhone + iFacialMocap ($5 one-time) → better tracking
