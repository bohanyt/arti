## PROBLEMS IDENTIFIED

### Problem 1: Toggle Mati Sendiri
**Symptom:** Bohan toggle ON, tapi somehow mati lagi / nggak konsisten dengerin

**Root cause:**
- `hotkey_active` flag nggak persistent — bisa reset atau ke-overwrite
- Nggak ada visual indicator apakah lagi listening atau nggak
- Toggle OFF harus manual (tekan mouse X2 lagi) — nggak auto-off

**Expected behavior:**
- Toggle ON → pasang tulisan/list icon yang jelas "ARTI LISTENING"
- Toggle OFF → icon hilang, Arti berhenti dengerin
- No accidental toggle

---

### Problem 2: Delay 3+ Detik Sebelum Bisa Ngomong
**Symptom:** Bohan nunggu ~3 detik baru bisa mulai ngomong, kadang malah ketuker mati

**Root cause:**
- `silence_duration >= 1.2` detik → baru transkrip
- Groq Whisper API latency (~1-2 detik)
- LLM generate (~2-4 detik)
- Total: 4-7 detik dari selesai bicara sampai jawab

**Expected behavior:**
- Kurangi silence threshold (coba 0.5-0.8 detik)
- Atau: langsung transkrip pas selesai bicara tanpa tunggu terlalu lama

---

### Problem 3: Harus Trigger Kata "arti"
**Symptom:** Bohan harus sebut "arti" dulu sebelum ngomong, padahal ini mic Bohan sendiri

**Root cause:**
- `trigger_mode = "wake_word"` — harus detect keyword
- Push-to-talk mode seharusnya LANGSUNG kirim ke LLM tanpa keyword

**Expected behavior:**
- Toggle ON → SEMUA suara langsung kirim ke LLM, nggak perlu trigger kata
- Toggle OFF → berhenti total

---

### Problem 4: Mic vs Chat Bentrok
**Symptom:** Kadang Arti malah respon chat YouTube, bukan omongan Bohan

**No root cause found** — ini mungkin perception issue karena delay

**Expected behavior:**
- Prioritas: Mic (Bohan) > Chat (Viewer)
- Kalau Bohan lagi ngomong, chat nggak interrupt

## SOLUTION DESIGN

### Solusi 1: Fix Push-to-Talk Priority

**Current code:**
```python
# Line 1137-1149
if trigger_mode == "push_to_talk":
    global hotkey_active
    use_groq = hotkey_active  # True kalau toggle ON

text = transcribe_audio(audio_array, samplerate, use_groq=use_groq)

if text:
    is_passive = (trigger_mode == "push_to_talk" and not hotkey_active)
    text = filter_whisper_hallucination(text, is_passive_monitoring=is_passive)
```

**Problem:** `use_groq = hotkey_active` — kalau True, transkrip pakai Groq. Kalau False, nggak transkrip.
Tapi `hotkey_active` bisa reset atau ke-overwrite.

**Fix:**
1. Tambah persistent state buat toggle
2. Visual indicator (print status jelas)
3. Pastikan toggle OFF total (nggak cuma nggak kirim ke LLM, tapi nggak transkrip sama sekali)

---

### Solusi 2: Kurangi Delay

**Current:**
```python
# Line 1131
if silence_duration >= 1.2:  # 1.2 detik diam = selesai bicara
```

**Fix:**
```python
# Kurangi ke 0.6-0.8 detik
if silence_duration >= 0.6:
```

**Plus:** Tambah early transcription — mulai transkrip sebelum selesai bicara (streaming).

---

### Solusi 3: Prioritas Mic > Chat

**Current:** Mic dan Chat masuk queue yang sama, first-come-first-served.

**Fix:**
1. Tambah priority flag di trigger queue
2. Mic trigger = priority HIGH
3. Chat trigger = priority LOW
4. Kalau ada mic trigger, skip chat trigger yang pending

---

### Solusi 4: OBS Subtitle (Word-by-Word)

**Goal:** Subtitle muncul per-kata pas Arti ngomong, kayak YouTube auto-captions.

**Approach:**
1. Extract word boundaries dari edge_tts
2. Kirim ke WebSocket server
3. Browser Source di OBS render per-kata dengan timing

**Implementation:**
- `subtitle_server.py` — WebSocket server
- `subtitle.html` — Browser Source HTML/JS
- Bridge kirim word_timings setelah TTS selesai
